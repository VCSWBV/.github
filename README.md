# VCSWBV defaults

Default community health files for the VCSWBV organisation. GitHub shows them in every repository that has no file of the same type:

- [SECURITY.md](SECURITY.md)
- [CONTRIBUTING.md](CONTRIBUTING.md)
- [Pull request template](.github/pull_request_template.md)

A repository's own file replaces the default completely, so a local CONTRIBUTING.md links here for the shared rules.

## What belongs here

This repository is public. It holds only what has to be public: the default community health files above and the public organisation profile in `profile/`. Everything else, such as shared workflows, shared configuration and internal documentation, lives in the private `VCSWBV/.github-private` repository.
